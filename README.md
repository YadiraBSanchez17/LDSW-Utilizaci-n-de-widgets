## Descripción

Este repositorio contiene las actividades desarrolladas para la materia de Diseño de Aplicaciones Móviles utilizando Flutter.

El objetivo es comprender la estructura de una interfaz gráfica mediante la implementación de widgets fundamentales y el diseño de una pantalla de inicio moderna.

## Widgets Utilizados

- Text
- Row
- Column
- Container
- Stack
- Image
- Icon
- FilledButton
